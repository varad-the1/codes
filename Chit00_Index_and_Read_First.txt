READ THIS FIRST
---------------
* Chits 1-5 and 7 are STM32F407 (STM32CubeIDE). Chits 6, 8, 9, 10, 11, 12 are
  ESP32 (Arduino IDE).
* STM chits that use PWM (4, 5): in the .ioc set clock source to HSI and use
  prescaler 15 (16 MHz / 16 = 1 MHz, so 1 count = 1 us). The Drive code was
  written with HSE at 168 MHz and prescaler 83 - both give the same 1 us tick.
  Pick one and be consistent with the clock config.
* After editing the .ioc press Ctrl+S to regenerate code, then put your code
  only between the USER CODE BEGIN / END markers or it is wiped on the next
  regenerate.
* Arduino chits: ESP32 serial monitor at 115200. Pick the correct board and a
  different COM port for each ESP32 when two boards are connected.
* Libraries (Arduino): DHT sensor library (Adafruit) + Adafruit Unified Sensor,
  Adafruit BMP280, PubSubClient. Install before the exam; the lab may be offline.
