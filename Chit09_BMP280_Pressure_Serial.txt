CHIT 9 | BMP280 pressure sensor (serial monitor)                  [ESP32]
======================================================================

Problem: Interface a BMP280 pressure sensor, acquire its output and display on
the serial monitor.
Code source: Drive Exp 5/Exp 5-a pressure sens ardinuo.txt; hehe.txt (Expt 5 PS1)

CONNECTIONS (I2C)
-----------------
BMP280 SDA -> GPIO 8, SCL -> GPIO 9, VCC -> 3.3 V, GND -> GND.
For the 6-pin module, if unsure which pin is which, use a multimeter to find
GND and VCC (your note). I2C address is 0x76 or 0x77; the sketch tries both.

STEPS
-----
1. Install "Adafruit BMP280 Library" (accept the Adafruit Unified Sensor dependency).
2. Upload, open Serial Monitor at 115200. Expect about 1000 hPa near sea level
   (Pune is lower, around 940-960 hPa).

CODE
----
#include <Wire.h>
#include <Adafruit_BMP280.h>

Adafruit_BMP280 bmp;

void setup() {
  Serial.begin(115200);
  Wire.begin(8, 9);                  // SDA = 8, SCL = 9

  if (bmp.begin(0x76)) {
    Serial.println("BMP280 Initialized");
  } else if (bmp.begin(0x77)) {
    Serial.println("BMP280 Initialized");
  } else {
    Serial.println("BMP280 Initialization Failed");
    while (1);
  }
}

void loop() {
  float pressure = bmp.readPressure() / 100.0;     // Pa -> hPa

  if (!isnan(pressure)) {
    Serial.print("Pressure: ");
    Serial.print(pressure, 2);
    Serial.println(" hPa");
  } else {
    Serial.println("Pressure Read Error");
  }
  Serial.println("--------------------");
  delay(1000);
}
